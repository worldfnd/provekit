An end-to-end ProveKit run starts with one circuit package and ends with a verified proof. The same `.pkp`, `.pkv`, and proof files are used by CLI workflows, SDK examples, verifier services, and recursive-verifier export.

## Working-directory rule

By default, the CLI resolves the enclosing Noir package from the current directory:

- `prepare` compiles `.` when no package path is provided.
- `prove` looks for `<package>.pkp` and `./Prover.toml`.
- `verify` looks for `<package>.pkv` and `./proof.np`.

For `noir-examples/basic`, the default files are `basic.pkp`, `basic.pkv`, `Prover.toml`, and `proof.np`.

<Aside type="tip" title="Prefer explicit paths in automation">
Default paths are convenient for local demos. CI jobs, services, and reproducible fixtures should pass explicit `--pkp`, `--pkv`, `--prover`, `--verifier`, `--input`, and `--out` paths.
</Aside>

## Artifact ownership

| File | Owner | Regenerate when |
| :--- | :--- | :--- |
| `<package>.pkp` | Prover-side runtime. | Noir program, compiler path, branch/commit, hash choice, or proving configuration changes. |
| `<package>.pkv` | Verifier-side runtime. | The prover key is regenerated, or verifier configuration changes. |
| `proof.np` | Proof transport/storage layer. | Inputs change, prover key changes, or a fresh proof is required. |
| `params_for_recursive_verifier` and `r1cs.json` | Recursive-verifier integration. | The verifier key or proof changes. |

## Local command sequence

<Steps>
1. Prepare keys.

   ```sh
   cargo run --release --bin provekit-cli -- prepare
   ```

2. Generate a proof.

   ```sh
   cargo run --release --bin provekit-cli -- prove
   ```

3. Verify locally.

   ```sh
   cargo run --release --bin provekit-cli -- verify
   ```

4. Optional: export recursive-verifier inputs.

   ```sh
   cargo run --release --bin provekit-cli -- generate-gnark-inputs \
     basic.pkv \
     proof.np
   ```
</Steps>

## Path overrides

Create the target directory before passing paths into it:

```sh
mkdir -p artifacts
```

Then run with explicit paths:

```sh
cargo run --release --bin provekit-cli -- prepare . \
  --pkp ./artifacts/basic.pkp \
  --pkv ./artifacts/basic.pkv

cargo run --release --bin provekit-cli -- prove \
  --prover ./artifacts/basic.pkp \
  --input ./Prover.toml \
  --out ./artifacts/proof.np

cargo run --release --bin provekit-cli -- verify \
  --verifier ./artifacts/basic.pkv \
  --proof ./artifacts/proof.np
```
