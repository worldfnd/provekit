Use this glossary when reading ProveKit docs, debugging artifacts, or writing integration runbooks.

## A–C

| Term | Meaning |
| :--- | :--- |
| <span id="acir">**ACIR**</span> | Abstract Circuit Intermediate Representation emitted by Noir before backend-specific lowering. |
| <span id="artifact-provenance">**Artifact provenance**</span> | The branch, commit, toolchain, lockfile, command line, feature flags, hash choice, and checksum record for a generated file. |
| <span id="bn254">**BN254**</span> | Elliptic curve whose scalar field is used for ProveKit's field arithmetic. Well-supported on EVM chains, making it a natural fit for the Groth16 recursive wrap. |
| <span id="circuit">**Circuit**</span> | The constrained computation being proven. In the default flow it is authored as a Noir package. |

## D–P

| Term | Meaning |
| :--- | :--- |
| <span id="ffi">**FFI**</span> | Foreign Function Interface. ProveKit exposes a C ABI for mobile and native hosts that cannot link Rust directly. |
| <span id="hash-choice">**Hash choice**</span> | The Merkle commitment hash selected by `prepare --hash`: `skyscraper`, `sha256`, `keccak`, `blake3`, or `poseidon2`. |
| <span id="noir">**Noir**</span> | Circuit language used by ProveKit's primary authoring flow. |
| <span id="pkp">**PKP**</span> | ProveKit prover key file (`.pkp`), produced by `prepare`, consumed by provers. |
| <span id="pkv">**PKV**</span> | ProveKit verifier key file (`.pkv`), produced by `prepare`, consumed by verifiers. |
| <span id="proof">**Proof**</span> | Serialized proof output, `proof.np` from the CLI, or JSON proof values in WASM and server flows. |
| <span id="public-inputs">**Public inputs**</span> | Values intentionally exposed by the circuit and bound into verification. Your application is responsible for interpreting them. |

## R–Z

| Term | Meaning |
| :--- | :--- |
| <span id="r1cs">**R1CS**</span> | Rank-1 Constraint System used by the ProveKit proving pipeline. |
| <span id="recursive-verifier">**Recursive verifier**</span> | Go/gnark wrapper that verifies a ProveKit proof inside an outer Groth16 proof for cheap on-chain settlement. |
| <span id="r1cs-json">**`r1cs.json`**</span> | Recursive-verifier R1CS export generated from a matching verifier key and proof. |
| <span id="params-recursive">**`params_for_recursive_verifier`**</span> | Recursive-verifier parameter file generated from a matching verifier key and proof. |
| <span id="skyscraper">**Skyscraper**</span> | Custom BN254-tuned hash engine used as ProveKit's default Merkle commitment and Fiat-Shamir transcript hash. |
| <span id="verifier-server">**Verifier server**</span> | HTTP service in `tooling/verifier-server` that downloads artifacts and orchestrates proof verification. |
| <span id="witness">**Witness**</span> | Private and public assignment values used to satisfy the circuit during proving. |
| <span id="whir">**WHIR**</span> | Hash-based polynomial commitment scheme used inside ProveKit's Spartan-based proof system. Provides the base proof's commitment layer and gives WHIR its name. |
