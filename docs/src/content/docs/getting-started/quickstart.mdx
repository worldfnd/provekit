This quickstart runs the shortest reliable path through ProveKit: prepare key material for the checked-in `noir-examples/basic` Noir package, generate a proof from `Prover.toml`, and verify the proof locally.

## Before you start

You need:

- A local ProveKit checkout.
- Rust installed through `rustup`.
- Network access for the first Cargo build.
- A shell starting from the repository root.

If any of those are missing, follow [Installation and setup](/getting-started/installation/) first.

## Run your first proof

<Steps>
1. Enter the example Noir package.

   ```sh
   cd noir-examples/basic
   ```

2. Prepare prover and verifier artifacts.

   ```sh
   cargo run --release --bin provekit-cli -- prepare
   ```

3. Generate a proof from `Prover.toml`.

   ```sh
   cargo run --release --bin provekit-cli -- prove
   ```

4. Verify the proof locally.

   ```sh
   cargo run --release --bin provekit-cli -- verify
   ```
</Steps>

The `--` before each subcommand is Cargo's separator between Cargo flags and `provekit-cli` arguments.

<Aside type="tip" title="Success signal">
A successful `verify` command exits with status code `0`. If verification fails, regenerate the artifacts from `prepare` in the same package directory before debugging CLI or verifier behavior.
</Aside>

## What each command reads and writes

| Step | Command | Reads | Writes |
| :--- | :--- | :--- | :--- |
| 1 | `prepare` | `Nargo.toml`, `src/main.nr`, Noir dependencies | `basic.pkp`, `basic.pkv`, Noir `target/` artifacts |
| 2 | `prove` | `basic.pkp`, `Prover.toml` | `proof.np` |
| 3 | `verify` | `basic.pkv`, `proof.np` | exits successfully when the proof verifies |

`basic.pkp`, `basic.pkv`, and `proof.np` are generated files. Do not commit them unless a downstream integration explicitly needs checked-in fixtures.

## Generated artifacts

| Artifact | Purpose | Default source |
| :--- | :--- | :--- |
| `basic.pkp` | ProveKit prover key generated by `prepare`. | The enclosing Noir package name plus `.pkp`. |
| `basic.pkv` | ProveKit verifier key generated by `prepare`. | The enclosing Noir package name plus `.pkv`. |
| `proof.np` | Proof generated by `prove` and consumed by `verify`. | `prove --out`, defaulting to `./proof.np`. |
| `Prover.toml` | Prover inputs for the example circuit. | Checked into `noir-examples/basic/`. |

## Clean up generated files

Return the example directory to a source-only state:

```sh
rm -f basic.pkp basic.pkv proof.np
rm -rf target
```
